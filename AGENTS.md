# Mailroom

## What this is

Mailroom is a command-line tool for one newsletter: MezbanPOS Newsletter.
It reads the subscribers, checks an issue, and sends it to a practice mail server.

## Rules

- Use uv for everything: running code, adding packages, running tests.
- Never use a real person's email address. Use addresses at @example.com, and @resend.dev for practice sends.
- Commit and push after every step.

## How I learn

- I am new to Python. I have completed up to 13.8 of https://agentfactory.panaversity.org/building-ai-workers/programming-fundamentals/ and I update this number as I learn.
- Write only with what I have learned. If something new would really help, stop and tell me its name in one line. I decide.
